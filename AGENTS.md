## Auth and tenant

- Login: Company Code (or Tenant ID) + Username or Email + Password. Tenant resolved by `company_code`.
- All tenant-scoped data has `tenant_id`; APIs filter by tenant. Tenant types: `manufacturer` | `buying_house` | `both`.
- **One user, one device (single session):** On for all tenants by default via `single_session_global` (env `SINGLE_SESSION_GLOBAL`, default `true` in `backend/app/config.py`). Newest login wins: each login bumps `users.auth_session_version` (JWT claim `sv`); older devices get `401 session_superseded` and the frontend redirects to `/login?reason=session_replaced`. Gate: `is_single_session_enforced()` in `backend/app/common/tenant_feature_keys.py`. Emergency off: `SINGLE_SESSION_GLOBAL=false` + restart backend (then per-tenant flag `single_session_enforced` decides). Runbook: `docs/RBAC_GO_LIVE_RUNBOOK.md`; tests: `tests/test_auth_session_version.py`.
