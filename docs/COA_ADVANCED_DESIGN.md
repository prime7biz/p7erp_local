# Chart of Accounts — Advanced Design (P7 ERP)

Short reference for the advanced Chart of Accounts implementation in the finance module.

## Overview

- **Account groups:** Already extended per `docs/ACCOUNT_GROUP_REDESIGN.md` (description, reporting_code, allow_posting, is_summary_group, last_reviewed_at). Hierarchy API returns these plus `depth`. Circular reference check on parent change.
- **Ledgers (chart_of_accounts):** New fields and behaviour below. Account codes remain auto-generated by default; format is configurable per tenant.
- **CoA config:** One row per tenant for code format and validation options.
- **Import/export:** CSV template for groups and accounts; conflict resolution on import.

## Data model (ledgers)

| Field | Purpose |
|-------|--------|
| **account_type** | `posting` \| `statistical` \| `header`. Posting = normal GL; statistical = non-monetary; header = roll-up only (no posting). |
| **reporting_code** | Optional statutory/external mapping. |
| **display_order** | Sort order in CoA list. |
| **statistical_unit** | For statistical accounts (e.g. Count, SqFt, Units). |
| **statistical_formula** | Optional notes for allocation/ratios. |
| **parent_account_id** | Optional self-FK for ledger hierarchy (Main → Sub account). |
| **last_reviewed_at** | Governance review date. |

## CoA config (tenant)

| Field | Purpose |
|-------|--------|
| account_number_prefix | e.g. `AC-` (default). |
| account_number_width | Numeric width (default 4). |
| group_code_prefix | e.g. `GRP-`. |
| group_code_width | Numeric width. |
| allow_manual_account_number | If true, user can supply account number on create (unique per tenant). |
| max_group_depth | Optional limit on group tree depth. |
| max_account_depth | Optional limit on account hierarchy depth. |
| validate_normal_balance | If true, ledger normal_balance must match group default_normal_balance. |

## Validation

- **Group parent:** On create/update of an account group, setting `parent_group_id` must not introduce a cycle (ancestor walk).
- **Normal balance:** When `validate_normal_balance` is true, create/update of a ledger checks `normal_balance` against the group’s `default_normal_balance`.
- **Posting:** Voucher create rejects lines whose account has `account_type = header` or whose group has `allow_posting = false`.

## API (summary)

- `GET/PUT /api/v1/finance/coa-config` — CoA config (PUT requires manager/admin).
- `GET /api/v1/finance/account-groups/{id}/reporting-impact` — Reports that use the group (read-only).
- `GET /api/v1/finance/coa/export` — CSV of groups and accounts.
- `POST /api/v1/finance/coa/import?conflict=skip|update|abort` — CSV upload; body = multipart file.

## Frontend

- **Chart of Accounts page:** Standard form + “Show advanced” (account_type, reporting_code, display_order, statistical_unit, parent_account_id, last_reviewed_at). Account number shown as read-only (auto-generated). Export CoA, Import CoA, CoA settings (config form).
- **Account Groups page:** Hierarchy and Advance design views; tree shows advanced fields; Reparent dropdown + Move; “View impact” opens reporting-impact panel (API). Standard/Advanced group form unchanged.
