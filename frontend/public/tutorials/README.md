# Tutorial screenshots, diagrams & videos

Static files for **Help & Tutorials** (`/app/tutorials`). Content that uses them lives in
`frontend/src/data/tutorials/sections/*.ts`.

```
public/tutorials/
├── screens/              # real app screenshots (JPEG) — generated by tools/tutorial-capture
├── videos/               # walkthrough videos (.webm) + <name>-poster.jpg — generated
└── diagrams/<section>/   # hand-made SVG diagrams (flows, document chains, status lifecycles)
```

Regenerate screenshots and videos with `tools/tutorial-capture/` (see its `README.md`); do not
edit those files by hand.

## Naming

- **kebab-case**. Sidebar screenshots use the route without `/app/`
  (`/app/inventory/purchase-orders` → `screens/inventory-purchase-orders.jpg`).
- Extra screenshots and videos start with the section prefix (`inv-`, `fin-`, `hr-`, `merch-`, …).

## Article references

Reference paths from the site root:

- `coverImage: "/tutorials/screens/inventory-purchase-orders.jpg"`
- `images: [{ src: "/tutorials/screens/foo.jpg", alt: "…", caption: "…" }]`
- `videos: [{ src: "/tutorials/videos/inv-create-po.webm", poster: "/tutorials/videos/inv-create-po-poster.jpg", title: "…" }]`
- Infographic `diagram`: `imageSrc: "/tutorials/diagrams/finance/voucher-lifecycle.svg"`
- Infographic `steps`: `steps: [{ title: "…", body: "…", imageSrc: "/tutorials/screens/…" }]`

Do **not** use external image or video URLs.

## Where they appear in the UI

- `coverImage` — article header, plus the thumbnail on hub cards; the first article with a cover also
  becomes the section's thumbnail under **Browse topics**.
- `videos` — top of the article and the hub's **Video walkthroughs** strip (uses `poster`, falling back
  to `coverImage`), and a **Video** badge on the article card.

## Accessibility

Every image needs **alt** text; use **caption** when the image needs a visible explanation.
Videos need a **title**; add a **caption** summarising what the video shows.

Run `npm run check` in `tools/tutorial-capture/` to find missing files and broken article links.
